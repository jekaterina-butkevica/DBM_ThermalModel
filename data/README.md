# Data

The datasets used in this study are archived separately from the GitHub repository.

The raw data are available from the associated data repository:

**https://doi.org/10.71782/DATA/WEXWIU**

Large data files are therefore not stored directly in this GitHub repository.

## Directory structure

To reproduce the analysis, create the following directory structure:

```text
data/
├── raw/
└── processed/
```

## Raw data

Download the archived datasets and place them in `data/raw/`.

The analysis uses the following input files:

### `P_xylostella_count_21_25.xlsx`

Diamondback moth (*Plutella xylostella*) pheromone-trap data collected in Latvia from 2021 to 2025.

The dataset contains trap-level observations including sampling site, year, sampling date, and the number of moths captured.

### `Meteo_21_25_observation_points.xlsx`

Daily meteorological data associated with the sampling sites.

The temperature data are used to calculate mean temperatures and degree-day accumulation between candidate flight-activity peaks.


## Processed data

The `data/processed/` directory is used for intermediate and final R objects generated by the analysis pipeline.

These files do not need to be downloaded separately. They are created automatically when the analysis scripts are run in numerical order.

Examples include:

- cleaned moth and meteorological datasets;
- candidate peak datasets;
- candidate generation-pair datasets;
- training and held-out test datasets;
- interval-selection results;
- fitted model objects;
- bootstrap results;
- final algorithm parameters.

## Reproducing the analysis

After downloading the raw data, the expected local structure is:

```text
DBM_ThermalModel/
├── data/
│   ├── raw/
│   │   ├── diamondback_count_21_25.xlsx
│   │   ├── Meteo 21-25.xlsx
│   │   └── Koordinātu_tabula.xlsx
│   └── processed/
├── R/
├── scripts/
└── README.md
```

The analysis can then be reproduced by running the scripts in the order described in the main repository `README.md`.
