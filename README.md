# DBM Thermal Model

This repository contains the R code used in the manuscript:

**Assessing thermal requirements of diamondback moth (*Plutella xylostella*; Lepidoptera: Plutellidae) in Latvia using time series of pheromone-baited trap catches**

The study uses pheromone-trap time series and meteorological data collected in Latvia from 2021 to 2025 to identify candidate generation intervals and estimate the relationship between temperature and development rate of *Plutella xylostella* under field conditions.

### `R/`

Contains reusable functions used throughout the analysis, including functions for:

- input validation;
- candidate peak detection;
- generation-pair construction;
- degree-day calculations;
- thermal-consistency-based pair selection;
- the reusable final analysis workflow.

### `scripts/`

Contains the sequential scripts used to reproduce the analyses reported in the manuscript.

Main analysis workflow:

1. `01_qc_and_corrections.Rmd` – data quality control and documented corrections;
2. `02_prepare_analysis_data.R` – preparation and standardization of moth and meteorological data;
3. `04_detect_peaks.R` – detection of candidate flight-activity peaks;
4. `05_generate_peak_pairs.R` – generation of candidate peak pairs;
5. `06_calculate_degree_days.R` – calculation of degree-day accumulation across candidate intervals;
6. `07_create_train_test_split.R` – creation of training and held-out test datasets;
7. `08_select_generation_pairs.R` – thermal-consistency-based interval selection;
8. `09_fit_generation_model.R` – fitting of the training temperature–development model;
9. `10_validate_generation_model.R` – held-out validation;
10. `11_refit_final_model.R` – fitting of the final model and bootstrap uncertainty analysis;
11. `12_estimate_peak_uncertainty.R` – estimation of uncertainty caused by trap-assessment timing;
12. `13_create_final_algorithm_parameters.R` – creation of the final reusable parameter set;
13. `14_test_final_workflow.R` – internal test of the reusable workflow;
14. `15_run_final_workflow_example.R` – example application of the final workflow.

Scripts used to generate manuscript outputs are also included:

- `figures.R` – manuscript and supplementary figures;
- `tables.R` – supplementary tables.

## Analysis overview

Pheromone-trap catches were standardized by sampling effort and used to identify candidate male flight-activity peaks within each site–year time series.

Because overlapping cohorts may cause chronologically adjacent peaks to represent different biological processes, all plausible peak pairs within a predefined duration range were generated as candidate generation intervals.

Candidate intervals were then evaluated using thermal consistency across site–year series. The retained intervals were used to estimate a linear relationship between mean air temperature and development rate.

Model robustness was evaluated using:

- a held-out test dataset;
- cluster bootstrap uncertainty estimates;
- influence diagnostics;
- sensitivity analyses;
- assessment of temporal uncertainty in peak timing.

## Reproducibility

The scripts should be run in numerical order.

Random procedures use a fixed seed of:

```r
2026
```

This includes the training/test split and bootstrap procedures.

The final reusable workflow can be applied to appropriately formatted new datasets using the functions in `R/` and the parameter set generated by `13_create_final_algorithm_parameters.R`.
